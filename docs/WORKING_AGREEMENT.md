## 2. Communication Protocols
- **Primary Chat Channel:** Team Facebook Messenger Group Chat.
- **Repository Issues & PRs:** All technical discussions, bug reports, and requirement clarifications must be logged directly on GitHub issues or PR comments.
- **Async Daily Standup:** Every team member posts a brief 3-bullet update by **11:00 AM** daily:
  1. What did I complete yesterday?
  2. What am I working on today?
  3. Are there any blockers or dependencies impeding my work?

---

## 3. Pull Request Review SLA
- **Review Turnaround Time:** Pull requests must be reviewed within **24 hours** of submission.
- **Review Etiquette:** Constructive feedback only; suggest concrete code improvements.
- **Merge Authority:** Once approved, the author (or Scrum Master) merges via **Squash and Merge** and verifies the corresponding issue is closed.

---

## 4. Blocker & Impediment Escalation
- If a developer is blocked by a missing database migration, API contract, or mockup for **more than 12 hours**, notify the Scrum Master (@HeindrichMacalinao) immediately in chat.
- The Scrum Master will coordinate an immediate huddle to unblock progress.
